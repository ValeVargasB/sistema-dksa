# Ventas y Apartados Web

Version sencilla en HTML, CSS y JavaScript con Firebase Firestore.

## Como usar

1. Abre `app.js`.
2. Revisa que `firebaseConfig` tenga los datos correctos de tu proyecto Firebase.
3. En Firebase Console habilita Firestore Database.
4. Crea reglas temporales de prueba si aun no usas login.
5. Abre esta carpeta con VS Code.
6. Instala la extension Live Server o usa cualquier servidor local.
7. Abre `index.html` en el navegador desde Live Server.

## Colecciones usadas

- clientes
- ventas
- articulosVenta
- abonos
- configuracion/general

## Nota

No uses reglas abiertas en produccion. Primero prueba la app, luego agrega autenticacion y reglas seguras.
